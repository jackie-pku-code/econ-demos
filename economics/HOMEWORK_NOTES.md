# 作业结构说明（导论 + 第一章）

依据曼昆《经济学原理》第 8 版（`mankiw_ch1_ch4_clean.md`）的选题，**考点与考察方式不变，只换成中国校园／日常的场景与数字**。题量按「大题」计，括号内为小问数。

## 文件与交互

| 文件 | 作用 |
|---|---|
| `intro/homework.html` | 导论作业：复习题 8 + 问题与应用 8 = **16 题（40 个小问）** |
| `ch1/homework.html` | 第一章作业：复习题 6 + 问题与应用 8 = **14 题（51 个小问）** |
| `assets/quiz.js` | 公共答题逻辑（页面内 `window.HW` 数据驱动） |
| `assets/site.css` | 末尾追加 `interactive homework` 样式（沿用 Apple liquid-glass 变量） |
| `index.html` / `intro/index.html` / `ch1/index.html` | 题量 tag 与按钮文案已更新 |
| `intro/lecture.html` | 已是 enriched 版本（幻灯式讲解），未改动 |

题型：`mc` 选择、`tf` 判断、`num` 数值（回车或「检查」）、`short` 简答（先自己写，再对照参考答案并自评）。

- 即时对错：点击／提交后立即变绿或变红，答错可重试；对了会自动展开讲解。
- 折叠讲解：每个小问都有「查看讲解」（简答为「参考答案与讲解」）。
- 进度：`localStorage` key 为 `intro` / `ch1`（`{小问id: {v, ok}}`，简答另存文字）；顶部有进度条，「重做」可清空。
- 打印 / PDF：顶部两个按钮——「题目」版（简答留横线，数值题留空格）；「含答案」版（展开讲解、标出正确选项）。直接 Ctrl+P 等同题目版。
